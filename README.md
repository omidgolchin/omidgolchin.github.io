# omidgolchin.github.io

Omid Golchin's personal site: one page that introduces him and gathers his nine public decision tools in one place, at https://omidgolchin.github.io/. It is plain HTML, CSS and a small JS file — no framework and no build step — styled with the omid-tools-kit tokens so it matches the tools. To change the tool list, edit the cards in `index.html` (name, one-line job, live link, code link) and put the card image, a WebP screenshot 600 px wide or less, in `assets/tools/`.
